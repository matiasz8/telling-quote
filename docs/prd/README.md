## PRD Format

Each PRD includes:
- Status (Planning, In Progress, Approved, Implemented, Deprecated)
- Objectives and user stories
- Acceptance criteria
- Success metrics
- Related documentation links

See `/docs/HOW-TO-PRD-TRD.md` for complete template.
